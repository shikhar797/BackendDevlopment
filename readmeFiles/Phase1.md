Q1.Definition of a server?
Ans1.A server is a program/process that provides a service to another program (client).
Client  ───── request ─────>  Server
Client  <──── response ───── Server

Q2. Frontend vs Backend

# Frontend
The part of the application that runs on the client side, usually the browser.
Examples:HTML,CSS,JavaScript,React,Angular,Vue
It handles things like:
UI
user interaction
displaying data
sending requests
basic client-side validation

# Backend
The server-side application responsible for things such as:
business logic
authentication
authorization
database access
APIs
validation
processing
communication with other services
